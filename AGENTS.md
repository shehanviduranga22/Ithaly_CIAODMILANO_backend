## Presentation rules
- Keep console layout and compact metric styling in the shared admin components so collection and reporting pages remain consistent.
- Use semantic theme tokens and shared Button variants for editorial controls so styling stays centralized.
- Keep collection browsing in the shared LinePage and item presentation in collection-items so all fashion lines share filters, views, and detail behavior.
